SMA CLIENT PORTAL — CLICKABLE PROTOTYPE

Isi prototype:
- Login magic-link
- Beranda klien
- Layanan Saya
- Detail layanan dengan tab Ringkasan, Dokumen, Pembayaran, dan Update
- Dokumen
- Pembayaran
- Profil
- Tampilan desktop dan mobile
- Modal serta toast interaktif dengan data dummy

Cara membuka:
1. Buka Terminal pada folder ini.
2. Jalankan:
   python3 -m http.server 8080
3. Buka http://localhost:8080

Prototype ini tidak tersambung ke Supabase dan tidak melakukan perubahan database.
Semua data bersifat dummy untuk validasi alur dan desain.
